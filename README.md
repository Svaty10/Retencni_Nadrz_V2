# ATtiny1624 Ultra-Low-Power Telemetry Sensor Node Firmware

Complete, deterministic, bare-metal C (AVR-libc) firmware engineered specifically for the **Microchip ATtiny1624** (SOIC-14) wireless telemetry sensor node powered by 3× Li-FeS2 battery cells (Energizer Ultimate Lithium L91).

---

## 2. Power Consumption & Sleep Budget

### Average Power-Down Sleep Current: **< 1.2 µA**
- **ATtiny1624**: Power-Down mode with 32.768 kHz ULP oscillator and PIT active: `~ 650 nA`.
- **BOD (Brown-Out Detector)**: Disabled during sleep (`BOD_SLEEP_DIS_gc`), enabled during active run (`BOD_ACTIVE_ENABLED_gc`): `0 nA` in sleep.
- **Digital Input Buffers**: Completely disabled on PA5, PA6, PB2 (`PORT_ISC_INPUT_DISABLE_gc`) to eliminate intermediate voltage leakage.
- **CC1101**: Strobe `SPWD` with CSN HIGH: `~ 200 nA`.
- **TPS63900**: Shutdown mode (`EN_5V_PROBE` = 0): `~ 30 nA`.
- **RT9073 LDO**: Quiescent current: `~ 1.0 µA`.
- **Battery Divider Q2/Q3**: Gate pulled to VBAT via 1 MΩ: `0 nA`.

## 3. Analog Front-End & Measurement Calculations

### 3.1. Battery Voltage Measurement (`ADC_BAT`)
- **Reference**: Internal $V_{REF} = 1.024\text{ V}$ (`VREF_REFSEL_1V024_gc`).
- **Divider**: $R_{top} = 1\text{ M}\Omega$, $R_{bot} = 220\text{ k}\Omega$ (1% tolerance).
- **Divider Ratio**: $K_{BAT} = \frac{220}{1000 + 220} = \frac{11}{61} \approx 0.180328$.
- **RC Filter**: $R_{eq} = 180\text{ k}\Omega$, $C = 22\text{ nF} \implies \tau \approx 3.96\text{ ms}$.
- **Settling Time**: $20\text{ ms}$ ($5\tau$) before ADC start.
- **Oversampling**: 16× hardware sample accumulation (`ADC_SAMPNUM_ACC16_gc`).
- **Integer Derivation**:
  $$V_{BAT}\ [\text{mV}] = \frac{S_{ADC} \cdot 61}{704}$$

### 3.2. Hydrostatic Level Probe (`ADC_PROBE`)
- **Reference**: Internal $V_{REF} = 2.500\text{ V}$ (`VREF_REFSEL_2V500_gc`).
- **Divider**: $R_{top} = 100\text{ k}\Omega$, $R_{bot} = 220\text{ k}\Omega$ (1% tolerance).
- **Divider Ratio**: $K_{PROBE} = \frac{220}{100 + 220} = \frac{11}{16} = 0.6875$.
- **Supply**: Switched 5.0 V generated by TPS63900 boost regulator.
- **Settling Time**: $40\text{ ms}$ for TPS63900 soft-start and sensor stabilization.
- **Oversampling**: 16× hardware sample accumulation (`ADC_SAMPNUM_ACC16_gc`).
- **Integer Derivation**:
  $$V_{PROBE}\ [\text{mV}] = \frac{S_{ADC} \cdot 625}{11264}$$

## 4. Sensirion SHT40 Temperature & Humidity Driver
- **Interface**: Hardware TWI0 at 100 kHz ($MBAUD = 11$ at $F_{CPU} = 3.333\text{ MHz}$).
- **Command**: `0xFD` (High-precision measurement: temp & RH).
- **Conversion Time**: Non-blocking waiting of $9\text{ ms}$ (max sensor spec is $8.2\text{ ms}$).
- **Bus Recovery**: Automatic 9-clock SCL toggling with STOP sequence if SDA gets clamped low.
- **Checksum**: Hardware-safe CRC-8 (polynomial $0x31$, initial $0xFF$).
- **Formulas**:
  $$T\ [0.1^\circ\text{C}] = -450 + \frac{1750 \cdot S_T}{65535}$$
  $$RH\ [0.1\%] = -60 + \frac{1250 \cdot S_{RH}}{65535}$$

## 5. CC1101 433 MHz RF Protocol & Radio Lifecycle
- **RF Configuration**:
  - Carrier: 433.92 MHz (26 MHz quartz).
  - Modulation: 2-FSK, Deviation ~25.4 kHz, Data rate 4.8 kBaud.
  - Power: +10 dBm ($PA\text{ Table} = 0xC0$).
  - Packet Engine: Fixed length (16 bytes), Hardware Whitening, CCITT-16 CRC.
- **Lifecycle Sequence**:
  1. Wakeup strobe by asserting CSN LOW.
  2. Wait for MISO to drop LOW (oscillator stabilized) with timeout.
  3. De-assert CSN, strobe `SIDLE` and `SFTX`.
  4. Burst write 16-byte payload into TX FIFO.
  5. Strobe `STX`.
  6. Wait for GDO0 to go HIGH (sync byte transmission started).
  7. Wait for GDO0 to go LOW (complete packet with CRC sent) with 100 ms timeout.
  8. Immediately strobe `SIDLE` followed by `SPWD`.

## 6. Battery Management & Failsafe Protection
- **Chemistry**: 3× Li-FeS2 (nominal 4.5 V, critical cut-off 3.0 V).
- **Under-Voltage Cutoff**: If $V_{BAT} < 3000\text{ mV}$:
  1. Transmits emergency `PACKET_TYPE_BAT_LOW` packet.
  2. Disables Watchdog Timer and RTC interrupts.
  3. Completely shuts down high-side MOSFETs and TPS63900.
  4. Disables digital input buffers on all pins.
  5. Enters permanent deep sleep to prevent battery cell reversal and brown-out reboot oscillations.

## 7. Building & Flashing

```bash
# Build firmware ELF, HEX, and generate size report
make all

# Flash via SerialUPDI
make flash PORT=COM3

# Burn hardware fuses (OSCCFG 20MHz, sampled BOD at 2.2V)
make fuses PORT=COM3
```
